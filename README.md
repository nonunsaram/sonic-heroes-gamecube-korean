# 소닉 히어로즈 GC 한국어 패치

제작: **노는사람 (nonunsaram)**

**영어 음성판 v1.1.0 최종본** — 미국판 GameCube의 영어 음성을 유지한 한국어 복원·번역수정 패치입니다.

## 다운로드

[영어 음성판 v1.1.0](https://github.com/nonunsaram/sonic-heroes-gamecube-korean/releases/tag/v1.1.0)에서 원하는 `.xdelta` **하나**를 받으세요.

| 판본 | 내용 |
|---|---|
| **복원판 · Restoration** | 원래 한국어 번역과 표현을 유지한 복원판 |
| **번역수정판 · Correction** | 명칭·오역·글꼴·미션 문구 교정 및 마지막 스토리 자막 복구 |

두 판본 모두 사용자 실행 확인과 패치 적용 결과 검증을 마쳤습니다.

## 설치

1. 깨끗한 **미국판 G9SE8P, Rev 0** ISO를 준비합니다.
2. xdelta 패처에서 원본 ISO와 원하는 패치 하나를 선택합니다.
3. 새 ISO로 저장하고 실행합니다. 결과 확인값은 [USA_CHECKSUMS.txt](USA_CHECKSUMS.txt)를 참고하세요.

**두 패치를 연속 적용하지 마세요.** 일본판이나 이미 패치된 ISO에는 적용할 수 없습니다.

지원 원본: `Sonic Heroes (USA) (En,Ja,Fr,De,Es,It).iso`  
크기: `1,459,978,240 bytes`  
SHA-256: `1F90FAD188B0904AC4C5F615F5553B3614694EEE7D22B87C54D988B0928DAC78`

복원판 참고: 언어 전환 뒤 한국어 선택 행이 투명해질 수 있으며, 일부 `으쌰！`가 `으！`로 표시되는 기존 제한이 있습니다.
